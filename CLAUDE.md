# Cómo actualizar este plugin

- Responder en español.
- Hacer los cambios en una rama y abrir un pull request; no subir directo a `main`.
- En cada versión, subir `version` en `.claude-plugin/plugin.json`.
- No cambiar el nombre del plugin (`esperanza-tv`).
- Antes de proponer el cambio: `claude plugin validate .`
- Nunca subir claves, videos ni proyectos de Premiere.
- No fijar rutas ni nombres de disco: la carpeta del proyecto se pregunta en cada tema.
